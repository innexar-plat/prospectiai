# Accessibility Policy

## Standards

- WCAG 2.2 AA mínimo, AAA preferível
- Leis: ADA (US), EAA (EU), LBI (BR)

## Auto-Checklist

- [ ] Contraste de cor ≥ 4.5:1 (texto normal), ≥ 3:1 (texto grande)
- [ ] Simular daltonismo: protanopia, deuteranopia, tritanopia
- [ ] Navegação por teclado: Tab, Enter, Escape, foco visível
- [ ] Leitor de tela: roles, labels, aria-*, landmark regions
- [ ] Textos redimensionáveis (zoom até 200% sem quebra)
- [ ] prefers-reduced-motion respeitado
- [ ] Touch targets ≥ 44x44px
- [ ] Mensagens de erro claras, não apenas cor
- [ ] Skip to content link
- [ ] Título de página único e descritivo
